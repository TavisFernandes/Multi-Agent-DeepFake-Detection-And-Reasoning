# Multi-Agent-DeepFake-Detection-And-Reasoning
This project uses visual, audio, and contextual verification agents coordinated by a PPO-based RL controller to detect deepfakes. The framework performs multimodal analysis, cross-modal contradiction detection, and generates explainable forensic reports.
